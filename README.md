# 九九ぱれーど

九九を段ごとに覚え、間隔をあけて繰り返し確かめる子ども向けWebアプリです。

- 1の段で操作を練習し、2〜9の好きな段から学習
- 「聞く」「順番に答える」「順番を崩して答える」の3段階
- 同じ日に間隔をあけて2回正解したら翌日へ。さらに日をあけて確認
- 9問全正解で段をクリアし、クリアした好きな段同士を10問ずつ混合
- 8段クリアと混合練習72種類の正解を経て、50問・81問のテストへ
- 段・範囲・問題を手動で選ぶ練習にも対応
- 通常の10問は正解中心で約45〜90秒。レクチャー・誤答時は合図と復唱の時間を確保。1日の目安は10分
- ホーム・めあて・記録・結果詳細を分け、スマホではスクロールせず画面を切り替えて操作
- 数字を運ぶ鳥、正解の印、進行ランプと段階的に変わるカラフルなステージ、拍に合わせた光、復唱中のダンス
- Web Audioで合成した音楽・効果音と、拍に合わせたSVG・Canvas・WebGLの演出
- VOICEVOX:春日部つむぎの事前生成音声。九九・合図・ほめ言葉・画面案内を収録。ホームのキャラクターを押すとあいさつ
- ホームで音声を先読みし、ゲームで使う段だけ準備。準備済みのゲームは待機画面なしで開始
- 学習記録はブラウザ内に保存。アカウントや通信による記録送信は不要

## 起動

`index.html` をブラウザで直接開きます。ビルドやパッケージのインストールは不要です。
Google Fonts以外の実行時外部依存はありません。フォントを取得できなくても利用できます。

本番: https://sahokun.github.io/kuku/

## 学習の仕様

詳しい判定・出題・時間の仕様は [docs/learning.md](docs/learning.md) にまとめています。
学習間隔や時間はアプリの初期設定値であり、効果を保証する数値ではありません。
今回の再設計前の版には問題ごとの学習記録がないため、新しい学習記録は最初から始まります。その版の音・演出設定は引き継ぎません。再設計後の版同士では学習記録・自己ベスト・カレンダーを引き継ぎます。旧回答時間設定の「ふつう」は一度だけ「おまかせ」へ移行し、移行後に手動で選んだ設定は保持します。
ブラウザや配信元を変えると記録は共有されません。

## ゲームと記録

- 「きょうのめあて」は1回完走・3回完走・1ゲームで3問正解の3つ。前日以前の復習対象がある日は「まえの九九をおさらい」を加えた4つになります。すべて達成するとカレンダーに花が残ります。
- 「九九のみち」は好きな段→クリアした段を合流→10問ずつの混合練習→50問・81問のテスト。50問は45問正解、81問は1の段も含む全問正解でクリアします。段のクリアと長期定着の★は別に管理します。
- チャレンジは段別9問、2段混合10問、50問・81問テスト。同じ問題の組で速さと正確さを比べ、コース別に自己ベストを保存します。
- 正解1000点（50問テストは3000点、81問テストは5000点）に速さ0〜30点と連続正解0〜20点を加算。復唱と一時停止は回答時間に含めません。
- カレンダーには実際に取り組んだ日・問題数・プレイ時間・ミッション達成を残します。以前の学習日も引き継ぎます。


- 九九マップは2〜9の段を3つの星で表示します。星は練習・日をあけた確認で増え、復習が必要でも獲得済みの星を残します。
- 回答時間は「おまかせ」が標準です。初めては制限なし、練習中は10秒、間隔をあけた正解を重ねた問題は5秒。開始前に今回の時間を変更でき、ゲーム中は固定します。
- 結果では問題・正しい答え・成否を5問ずつ確認できます。誤答では入力した答えも表示します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面構造とスクリプトの読み込み |
| `css/` | 画面・数字キー・レスポンシブ表示。`theme.css` は配色・ボタンの優先順位・共通ナビゲーション |
| `js/data.js` | 九九81問と日本語の読み |
| `js/learning.js` | 学習判定・出題計画・保存データの検証。DOMに依存しない |
| `js/results.js` | 回答履歴の表示と5問ごとのページ分け |
| `js/rewards.js` | 得点、比較可能なコース、自己ベスト、日ごとのめあてとカレンダーの保存規則 |
| `js/journey.js` | めあて・段のルート・チャレンジ・カレンダー・結果の画面 |
| `js/store.js` | localStorageの読み書き、回答後の遅延保存、保存失敗時の継続 |
| `js/viewport.js` / `css/layout.css` | ブラウザの表示領域に合わせた画面サイズと、機能別の画面配置 |
| `js/app.js` | 画面、入力、ゲーム進行、停止と復帰、日次時間 |
| `js/recitation.js` | 読み上げ完了に合わせた「聞く・合図・復唱」の進行 |
| `js/sound.js` | 音楽・効果音の合成と録音音声の再生 |
| `js/voice-files.js` / `js/voice-manifest.js` | 音声ファイルの読み込み・展開・再利用と位置情報 |
| `audio/tsumugi/` | 九九・合図のMP3、直接ファイルを開く場合の同内容のJS、音声一覧 |
| `js/visuals.js` | 入力・正解・復唱の振り付け、SVGマスコット、前面と背面のCanvas、WebGL背景 |
| `js/diagnostics.js` | `#diagnostics` のときだけ動く実機入力計測。描画・タイマーの間隔、入力・音声・保存処理を記録 |
| `tests/*.test.cjs` | 学習・出題・復唱・音源・スコア・めあて・保存の自動テスト |
| `tools/verify-browser.mjs` | 起動済みChromeに接続する学習・音声・保存のブラウザ検証 |
| `tools/verify-mobile.mjs` | スマホ8サイズの全画面・初期倍率・CPU負荷を確認 |
| `tools/verify-voice.mjs` | 録音の範囲・読み込み待機・失敗時の再試行・中断を既存Chromeで確認 |
| `tools/verify-diagnostics.mjs` | 診断条件の切替、停止の検出、通常の学習データの保護を既存Chromeで確認 |

## テスト・確認環境

学習ルールの自動テストはNode.jsで実行できます。

```sh
node --test --experimental-test-isolation=none tests/*.test.cjs
```

ブラウザ検証ツールの実行方法・保存データの扱い・出力先は [tools/README.md](tools/README.md) を参照してください。

ローカルの `develop` が動作確認用、`main` が本番です。開発者本人限定のスマホ確認にはChatGPT Sitesを使い、配置先を `.openai/hosting.json` に記録します。本番のGitHub Pagesとは別に更新します。
GitHub Actionsは学習ルールを検証し、本番の配信は `main` へのpushだけで行います。本番へのPR・マージはユーザーが行います。
