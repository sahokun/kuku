# 九九ぱれーど

九九を おぼえる ゲームだよ。
きいて、いっしょに いって、じぶんで こたえて、すこしずつ おぼえよう。

## あそぶ ところ

https://sahokun.github.io/kuku/

スマホでも パソコンでも あそべるよ。

## あそびかた

1. さいしょは 1のだんで、あそびかたを おぼえよう。
2. すきな だんを えらぼう。「きく」→「じゅんばん」→「ばらばら」の じゅんに すすむよ。
3. ばらばらの 9もんが ぜんぶ できたら、その だんは クリア！
4. クリアした だんを まぜて、10もんずつ れんしゅうしよう。
5. 2から 9の だんが ぜんぶ できたら、50もんと 81もんの テストに ちょうせん！

## たのしい しかけ

- きょうの めあて：ぜんぶ できると、カレンダーに 花が さくよ。
- 九九マップ：おぼえた 九九に ★が ふえるよ。★3つは、日を あけても すぐ いえた しるし。
- わからない ときは「わからない」を おすと、ヒントが 出るよ。
- まちがえても だいじょうぶ。こたえを きいて、いっしょに いってみよう。
- 1日 10ぷんくらいが めやすだよ。
