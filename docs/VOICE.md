## 内容と再生

- 九九81通りの全文、出題用の前半81通り、復唱の合図、案内・ほめ言葉・励まし・結果の26種類で計189音声。MP3合計約1.84MB。
- 追加フレーズの文面は `audio/tsumugi/phrases.json` で管理します。ホームのキャラクターを押すとあいさつします。画面案内は初回だけ、ほめ言葉は正解の節目、励ましは誤答の練習後に再生します。九九の音声には重ねません。
- `audio/tsumugi/*.mp3` に段ごとに保存。全文は一続きの音声で、再生時に単語をつなぎません。
- `manifest.json` と `js/voice-manifest.js` が全文と開始位置・長さを対応付けます。
- `audio/tsumugi/*.js` は同じMP3のBase64表現です。直接 `file://` で開いたときだけ使用します。HTTP配信ではMP3のみを読みます。
- ホームでおすすめの段と共通音声の圧縮データを先読みし、プレイ前には出題範囲の段だけデコードします。単一の段なら段・合図・共通フレーズの3ファイル（4の段で約644KB）。混合では対象の段を追加します。準備済みなら待機画面を出しません。読み込み時間は学習時間・回答時間に含めません。
- BGM・効果音と同じAudioContextで再生します。声と音楽の音量・有効設定は独立しています。Web Speech APIは使用しません。
- 読み込み失敗時は再試行または声なしでの継続を選べます。端末の読み上げへの切り替えはありません。

## 再生成（開発時のみ）

使用バージョンはVOICEVOX Core 0.17.0、音声モデル0.16.4の `0.vvm`、VOICEVOX ONNX Runtime 1.17.3、Open JTalk辞書1.11。公式配布元から取得してください。

Python環境に公式の `voicevox_core` とPyAVを入れ、次を実行します。

```sh
python tools/generate-voice.py --runtime /path/to/libvoicevox_onnxruntime.so.1.17.3 --dict /path/to/open_jtalk_dic_utf_8-1.11 --model /path/to/0.vvm
```

九九の読みは `js/data.js` から取得し、カナで発音を指定します。「しは」「ごは」などの「は」を助詞と誤読しないよう、文章解析に委ねません。MP3は24kHz・モノラル・64kbpsです。生成ツール・モデルは配信物に含めず、利用者はインストール不要です。

フレーズだけの変更時は `--banks messages` を付けると、九九の音声を変更せずに再生成できます。
