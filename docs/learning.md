# 学習とゲーム進行

## 目標と時間

九九の答えを思い出す反復練習。1ゲームは通常10問、段の導入と順番練習は9問。同じ問題の再出題も1問と数える。
自力正解後は九九を答えまで1回読み上げ、「こたえを きこう」と表示する。正解時は子どもに復唱を求めない。音声終了後900msの余裕をあけて次へ進む。誤答・「わからない → こたえをきく」・時間切れでは、正答を表示して復唱に進む。間違いの動きと九九の読み上げ → 「いってみよう、せーのっ！」の音声 → 同じ九九をもう一度読み上げる。各音声の終了を待ち、最後に900msの余裕をあけて次へ進む。その場で再入力を求めない。
自動で正答を提示するまでの時間は、おまかせまたは手動設定で決める。制限なし・10秒・5秒・3秒・1.5秒があり、初期値のおまかせは学習記録に合わせる。最初の数字入力には設定に応じた猶予を設ける（詳細は「回答時間の設定」）。削除や追加入力で延長を繰り返さない。
1桁または2桁の答えがそろうと自動判定し、確定ボタンでも回答できる。

導入のレクチャーも、九九を聞く → 音声の合図 → 九九に合わせて言う、の同じ流れを使う。固定秒数や途中のスキップでは進めず、読み上げ終了を待つ。1の段は最初の3問で読み聞きを体験し、残り6問で入力・答えを見る操作を練習する。
通常の10問は、正解が多ければ答えの音声確認を含めて約45〜90秒を想定する。復唱を多く含む回や段のレクチャーは長くなり、音声の長さにより1〜2分以上かかる場合がある。1日10分は回数ではなく実際のプレイ時間で集計する。

ゲーム画面で実際に進行している時間を日ごとに合算する。問題間の短い演出も含め、ホーム・結果・一時停止・バックグラウンドの時間は含めない。10分に達したゲームの結果画面では終了を主操作にする。続けることも可能で、翌日へ時間のノルマを持ち越さない。

## 段の進行

1. 1の段は初回チュートリアル。以後の自動出題と72問の定着集計から除く。手動では選べる。
2. 2〜9の段を好きな順で選ぶ。段ごとに9問の読み聞き、9問の順番練習、順番を崩した9問のテストへ進む。
3. 段のテストで9問全問正解すると「段のクリア」。長期定着の★とは別で、翌日の復習も必要。既存データの全9問当日確認済みの段と、過去の段別テスト全問正解もクリアとして引き継ぐ。
4. クリアした段を2つ以上自由に組み合わせ、10問ずつ混合練習する。全クリア段の一括選択もでき、選択は保存される。1回の10問は重複せず、選んだ各段を均等に含む（差は最大1問）。同じ段の候補では確認間隔を満たす問題、混合でまだ正解していない問題、復習期限の来た問題を優先する。
5. 混合練習の完走回数と正解した問題の種類を保存。10問未満で中断しても回答済みの学習記録は残るが、混合コースの進捗は増やさない。全問正解は混合練習の完走条件ではなく、誤答した問題は後の回で再確認できる。
6. 8段をクリアし、混合練習で72種類それぞれに正解すると50問・81問のテストが同時に開く。50問テストは2〜9の全段を6〜7問ずつ含む固定の50種類を毎回並べ替える。45問以上正解でクリア。81問テストは1〜9の段の全81種類を重複なく並べ替え、全問正解した完走だけをクリアとする。途中終了や80問正解ではクリアにならず、50問とは自己ベストとクリア記録を分ける。すべての九九の長期定着を保証する試験ではなく、合格後も間隔反復と★の確認を続ける。

50問テストは約4〜8分、81問テストは約7〜12分を想定（回答時間・誤答時の復唱・音声の長さで超える場合もある。制限なしでは所要時間の上限を設けない）。一時停止できるが、終了・再読み込みした未完走テストの再開はしない。通常の10分目安は維持する。
ホームは選んだ段の続き、クリア後は選択済みの混合10問を案内する。混ぜられる段が1つだけなら段を選ぶ画面へ進む。ほかの段を選ぶために現在の段を終える必要はない。マップの★と段のクリアを分け、クリア・最終合格によって星や復習期限を変更しない。
手動では1〜9の段、連続した範囲、任意の組み合わせ、個々の問題を選べる。手動練習も共通の記録へ反映するが、短時間の繰り返しでは定着段階を上げない。

## 問題ごとの定着

`a×b`を識別子とし、`7×8`と`8×7`は別に管理する。記録には回答回数、自力正解回数、当日の確認数、最終提示時刻、間に挟んだ回答数、復習期限、定着段階、直近24回の回答履歴を含める。

- 一度目の自力正解だけでは当日確認完了にしない。
- 当日の2回目は、同じ問題の前回提示から別の問題を5問以上、かつ30秒以上あける。順番を崩した出題での自力正解が必要。
- 順番練習は最初の1回としてのみ数える。読み聞き、答えを見た回、誤答は自力正解に数えない。
- 答えを見た後は最低3問を挟んで確認する。同じ問題を間隔不足で再提示した場合も、間隔はその提示から測り直す。
- 当日2回の確認後、翌日以降の自力正解で次の期限を3日後、さらに正解すると7日後にする。その次の確認に成功すると定着完了とし、星3個にする。
- 日をまたいだ確認では、前日から別の問題を5問挟んでいることは求めない。未完了の当日1回分は翌日に合算しない。
- 定着完了後は14日間隔で維持確認する。
- 誤答・答えを見る・時間切れがあれば、当日の2回確認からやり直す。過去の星や次の段への進行履歴は取り消さない。

九九マップは2〜9の段の72マスを表示する。未着手は薄い空のマス、練習中は星の輪郭、同日の間隔をあけた2回正解で星1個、別日の確認で星2個、従来の定着条件を満たすと星3個と金色のマスになる。獲得した最大の星数は保存し、誤答で取り消さない。復習期限が来た場合や再練習中はオレンジの印を添える。完成数は星3個で再練習中でない問題を数える。1の段はマップの外のチュートリアルボタンに分ける。
日付は端末のローカル日付を使い、欠席で学習結果を消さない。復習期限より早い手動正解では確認段階を進めない。

## 得点とチャレンジ

導入以外の練習では、正解のたびに1000点を加算する。50問テストは3000点、81問テストは5000点とし、正解数が1問多い価値が速さ・連続の加点より高いことを保つ。回答が1.5秒以内なら速さ30点、そこから5秒までは線形に減らして整数へ丸め、5秒以降は速さ0点。連続正解は2問目から4点ずつ増やし、最大20点。誤答・答えを見る・時間切れは0点で、連続正解の数だけをリセットする。獲得済みの点は減らさない。

計測は問題の提示から最初の回答確定までの実際に操作できる時間。一時停止・非表示・回答後の復唱は除外する。回答時間の概ね50msごとの計測は既存の入力タイマーと共通。導入の読み聞きには点を付けない。

自己ベストは専用チャレンジの完走時にコース別で保存する。コースは2〜9の段それぞれ9問と、2・3／4・5／6・7／8・9の段を混ぜた各10問、および50問・81問。9問・10問は対応するすべての段の順番練習を終えると遊べる。50問・81問は上述のルート条件で開く。1の段は81問テストだけに含める。2段混合は各段5問ずつの固定した10種類を使う。旧18問コースの自己ベストは別枠で保持し、10問の得点と比較しない。各コースではそのコースの問題を1回ずつ、順番を変えて出題する。毎回同じ問題集合なので、違う段・出題数・問題の組の記録を直接比較しない。通常の混合10問・手動練習のスコアは自己ベストへ登録しない。

9問・10問・50問・81問とも、正解数が1問多ければ速さ・連続正解の差にかかわらず高得点になる。記録には得点、正解数、回答時間合計、日付、完走回数、直近の結果を保存する。以前より得点が高い場合だけ自己ベストを更新する。同点・低得点でも過去のベストを失わない。未完走・重複問題・違う問題集合は記録しない。

加点は点数表示の反応と飛び込む数字で伝え、進行中に前のベストを超えると祝う。記録の確定は完走後。結果画面の先頭に得点、速さ・連続正解の加点、自己ベストとの差を表示する。「同じコースでもう一度」では新しく順番を変える。スコアや自己ベストで学習の定着段階・星を進めない。

## めあて・段のルート・カレンダー

「きょうのめあて」は「1かい さいごまで あそぼう」「3かい さいごまで あそぼう」「1かいで 3もん せいかいしよう」を毎日表示する。前日以前に取り組んだ復習期限内の問題がある日は「まえの 九九を おさらいしよう」を4件目に加える。対象がない日は達成不能なめあてを表示しない。その日の最初におさらい対象を固定して保存する。

完走は問題数をすべて終えた回だけを数え、中断は数えない。導入も完走に含む。1回で3問正解は、その回の正解数で判定し、別々の回の正解を合計しない。途中に誤答があってもよく、3問目の正解時点で達成する。その日の最高の1回分の正解数を保存する。旧データの累計正解数からこの記録を推測しない。

おさらいは対象を1問、答えの確認まで終えると達成する。誤答でも復唱を最後まで終えれば数えるが、問題の定着判定は従来の規則を維持する。実際の発声をマイクで判定する機能はない。おさらいのめあてからは対象だけの10問を開始し、対象が少ない場合は繰り返す。

表示されている3件または4件をすべて満たすと、その日に一度だけカレンダーの花を獲得する。達成通知は入力を止めない。10分を超える条件、連続ログイン、速さだけを要求する条件は設けない。旧条件で獲得済みの花は移行で消さない。日付が変われば新しいめあてになり、過去の花は保持する。

「九九のみち」は独立した8段のカードから混合練習へ合流し、50問・81問のテスト選択へつながる。1の段は別のチュートリアルボタン。各段には段のクリアと長期定着の星を表示する。混合ステーションには段の選択、選択した範囲で正解した種類数、完走回数と花のスタンプを表示する。テスト選択には解放までの残り条件と各テストのクリア条件を示す。星の再確認が必要な場合も過去の獲得数を表示し、おさらいの案内を加える。

カレンダーは月単位で移動でき、日付から時間・問題数・完走回数・めあて達成を確認できる。取り組んだ問題がある日にだけプレイ印を付け、画面を開いただけでは付けない。未来の月には進まない。記録は最大730日分、旧データにある学習日は引き継ぎ、昔のミッション達成を推測して付与しない。休んだ日があっても過去の印を消さない。

## 画面とスマホでの操作

ホームはおすすめの練習名・所要時間・開始ボタンを一つの枠にまとめ、今日の時間とめあてを表示する。下部の「ホーム・あそぶ・きろく・メニュー」は現在地を強調し、ゲーム・結果中は非表示にする。詳細画面の「もどる」は開いた画面へ戻る。黄色・黒・白の配色とテレビ風の枠を用い、黒地の開始ボタン、白地の行き先ボタン、文字のみの補助操作で優先順位を分ける。手動選択は段ボタンと範囲選択をタブで切り替える。段のルートは段選択・混合練習・テスト選択のタブ、チャレンジは段別・混合のタブで切り替える。個別問題選択も専用画面。結果は得点・正解数・続ける／終わる操作を同じ画面内に置き、内訳と学習進捗は結果詳細へ分ける。
各画面はVisualViewportの高さ（未対応時はinnerHeightとsvh）に追従し、スクロールではなく遷移で情報へアクセスする。ゲームのステージとキー領域は余った高さを配分する。横向きは左右2列へ切り替える。選択欄の文字は16px以上として自動拡大を避ける。ユーザー自身のピンチズームは禁止しない。

## 音・描画・停止

主役のキャラクターは独自のパーツ分割SVG。小さな仲間と紙吹雪用の鳥は起動時に画像化して再利用し、仲間の跳躍・回転は要素全体の変形で描く。見えない仲間のパーツは更新しない。入力の鳥は前面のCanvas、紙吹雪・リボン・音符は背面のCanvasに分け、問題カードと操作ボタンを読める状態に保つ。背景はWebGLで色の流れと浮かぶ小片を描き、未対応・コンテキスト喪失時はCSSへ切り替える。

- 数字キーは押し込みと反発で反応し、小さな鳥が数字を答えへ運ぶ。
- 正解すると答えと「できた！」の印が弾み、星がラウンドの進行ランプへ飛ぶ。直後と少し遅れた二段階で紙吹雪・光の輪・リボンを出す。ランプは学習の定着ではなく、この回の進行を表す。
- 通常10問では3・6・8問の節目で仲間、照明、背景、音楽が変化する。最大6体の仲間が踊り、最終段階では王冠と花火が加わる。誤答でも復唱を終えれば進行し、演出の段階は下がらない。
- 正解の復唱中は笑顔と口の動きで一緒に歌い、音符を出しながら踊る。誤答・導入では合図と復唱に動きを合わせる。音声の終了を待つ学習進行は維持する。
- 完走時は専用の終わりの曲と約5.5秒の花火で祝う。結果画面の操作は花火の終了を待たない。

BGM・効果音はWeb Audioで合成する。音声はVOICEVOX:春日部つむぎで事前生成したファイルを同じAudioContextで再生する（生成方法・利用条件はVOICE.md）。4小節の和音と旋律を使い、キック、低音、手拍子、細かいリズム、和音、終盤の主旋律を重ねる。正解音は伴奏と同じ和音に合わせ、3連続正解ごとに追加の音を鳴らす。復唱中は旋律と打楽器を別々に小さくして、読み上げの聞き取りやすさを保つ。音楽の拍に背景・キャラクターが反応し、無音時にも独立したリズムで動く。

粒子は260個、リボンは18本、音源は64個を上限とし、前面の演出は最大約60fps。背景は通常約30fps、正解直後の光は優先して更新する。Canvas解像度はタッチ端末で1.1倍、その他で1.5倍まで。WebGLは画面寸法の0.48倍／0.6倍に制限する。描画負荷が続いた場合は粒子数や仲間の数を変えずに内部解像度を段階的に下げる。座標の読み取りは画面変更・問題変更・リサイズ時にまとめ、回答直後にレイアウトの再計算を繰り返さない。音源は終了時に切断する。

音楽・効果音と音声読み上げは別設定。初期値は音楽オフ、読み上げオン。「おと なし」「おと あり」で音楽の状態を表示する。音量と動きの強さを調整でき、動きを減らすOS設定があれば初期値に反映する。動き0では跳躍・粒子・拡縮・フェードを止め、文字と色で結果を伝える。
一時停止・タブ非表示では入力の期限とプレイ時間を止め、音と演出も停止する。復帰時には明示的に再開する。復唱中の再開では、その段階の音声を最初から再生する。音声オフ・音声未対応・読み上げ失敗時は、同じ画面の合図と発声用の時間を確保する。音声終了イベントが届かない場合にも進行不能にならないよう上限待ち時間を設ける。問題ごとの記録は回答時にメモリへ反映し、空き時間（上限700ms、未対応環境は80msのタイマー）に保存する。一時停止・終了・非表示・ページ離脱時は保留中の保存を即時実行する。中断した未回答は誤答にしない。

## 保存と検証

保存キーは `kuku:learning:v1`。追加の得点・めあて・カレンダーは同じ保存データ内の `rewards` に独立したバージョンを持たせ、従来の学習記録をそのまま復元する。日次集計は直近90日、問題ごとの履歴は直近24回。保存できなくても、その場のプレイは続けて画面で知らせる。
旧設定は削除せず、新しいキーで記録する。ブラウザ・配信元・端末間での同期はない。
Node.jsで学習規則・出題の停止条件・保存復元を検証する。ブラウザ検証では時計を一時的に進めて操作と時間切れを確認し、その後に実際の音声と時計で10問を通して、正解・復唱・各段階の演出・一時停止・動き0の状態を確認する。スマホ検証は320×480〜430×740の縦向き7条件と844×390の横向きで、全画面の操作・文字の収まりと初期倍率を確認する。さらにCPUを4倍遅くしたChromeで10問連続正解の処理時間と長い処理を計測する。実際の音の聞こえ方・読み上げ速度・GPU性能は端末により異なるため実機確認も必要。


## 回答時間の設定

「せってい」の「こたえる じかん」で、おまかせ・はじめて（自動表示なし）・やさしい（10秒）・ふつう（5秒）・むずかしい（3秒）・ろぼっと（1.5秒）を選ぶ。初期値はおまかせ。旧版のふつうは初回だけおまかせへ移行し、それ以外の手動設定や移行後に選んだふつうは保持する。おまかせは出題予定の問題集合（動的出題では候補全体）の学習履歴から決める。回答経験がない問題や直近2回とも誤答の問題があれば制限なし。その他は、すべての問題が同日の間隔をあけた確認に達し、再練習中でなく直近も正解なら5秒、それ以外は10秒。導入は常に制限なし。自動では3秒・1.5秒へ進めない。導入以外は開始前に今回の時間を表示し、その1回だけ変更できる。ゲーム中は時間を固定する。コース記録には自己ベスト・直近それぞれの時間設定を残し、古い記録の設定を推測しない。出題・入力開始時に短い2音の合図を鳴らす。合図は音楽・効果音の設定と音量に従い、導入の聞くだけの場面では鳴らさない。

1桁目の入力後は、通常の期限と「入力から猶予時間」の長い方まで待つ。猶予は回答時間の36%、上限1.8秒。ふつうは従来と同じ挙動。はじめては時間切れにならず「わからない → こたえをきく」で進める。一時停止・音声準備・答えの確認中は回答の期限を進めない。10秒を超えて正解した場合も段のクリアやスコアを記録できる。速さの加点は従来どおり5秒までで、設定による加点の変更はない。

結果の「もんだいと こたえ」では今回の各問題・正しい答え・成否を出題順に表示する。誤答は入力した答え、時間切れ・答えの表示はその理由を添える。導入は不正解とせず聞いたことを示す。5問ずつページ切り替えし、81問の結果も画面をスクロールさせない。
